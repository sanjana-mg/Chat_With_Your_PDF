# Chat With Your PDF

An AI-powered PDF Question Answering Application using Python, RAG (Retrieval-Augmented Generation), and Generative AI.

## Project Overview

Chat With Your PDF allows users to upload PDF documents and ask questions based on their content. The application extracts text, processes it, retrieves relevant information, and generates answers using AI.

## Features

- Upload PDF documents.
- Extract text from PDF files.
- Split text into smaller chunks.
- Generate text embeddings.
- Store and retrieve information using a vector database.
- Ask questions about uploaded documents.
- Generate AI-powered answers.
- Display relevant source information.

## Technologies Used

- Python
- Streamlit
- PyMuPDF
- Sentence Transformers
- ChromaDB
- Google Gemini API
- Git and GitHub

## Installation

1. Clone the repository.
2. Create a Python virtual environment.
3. Install dependencies using:

   pip install -r requirements.txt

4. Configure your Gemini API key in a .env file.

5. Run the application.
